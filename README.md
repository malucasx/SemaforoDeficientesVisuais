# Semáforo Deficientes Visuais Davi
Projeto feito por mim

Durante meu período na faculdade(2019), nos foi solicitado a criação de um projeto em Arduino, minha escolha na época foi a criação de um semáforo que fosse útil as pessoas cegas.
Tinhamos aprendido sobre C algumas semanas antes, então achei a oportunidade perfeita para ver oque era possível criar com meu nível de conhecimento, no final gostei muito do resultado e achei plausível compartilhar em meu git, 
vocês podem ver o código usado na criação no arquivo "CodigoArduino" e caso queiram  ver executando pode acessar no Tinkercad através do link abaixo:
https://www.tinkercad.com/things/36c67o8NOch-semaforo-para-deficientes-visuais
